# 开发 AscendForge（昇腾工坊）

读取项目需求、现有代码和部署环境，优先复用已有模块。采用服务器部署与浏览器控制，禁止将优化循环放在客户端；确保网页关闭后服务器 worker 继续运行。实现服务访问认证、服务端凭据保存、浏览器下载备份和状态重连。

先核实平台真实交互与自动化规则，记录证据及未知项。先完成真实登录、单次提交、结果读取，再实现自动迭代。没有真实账号或平台条件时保留未验收状态。

分离平台适配器、模型 Provider、Agent Runtime、隔离执行器、调度器和实验存储。将工具设计为带版本的结构化协议，由宿主校验后执行。

为同账号实现持久化提交队列，原子执行限频和额度检查。对提交响应未知先对账，不盲目重发。重启先恢复在途状态。

先保存不可变源码快照和摘要，再提交快照对应字节。绑定远端提交 ID、原始结果与归一化结果。

将凭据限制在适配器与 Provider，避免进入模型上下文和普通日志。隔离运行生成代码并限制资源。

针对重复提交、并发额度、状态恢复和 best 更新写行为测试；将 mock 与真实验证结果分别报告。每阶段报告成果、验证证据和剩余阻塞。
